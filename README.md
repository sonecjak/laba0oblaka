# Что было сделано

В качестве идеи взяли простое приложение «Заметки». Логика такая:

- на странице есть поле ввода и кнопка «Добавить»;
- вводим текст, нажимаем — заметка уходит на сервер;
- сервер сохраняет её в базу;
- список заметок отображается тут же, под формой;
- если обновить страницу - заметки остаются на месте, потому что лежат в базе, а не в HTML.


Очень крутое милое приложение "Заметки":
- **Backend**: Python (Flask) — `backend/app.py`
- **Frontend**: одна HTML-страница с формой и списком — `frontend/index.html`
- **DB**: PostgreSQL (отдельный сервис, поднимается через Docker) (который оказывается нужно не забывать запускать)
  
<img width="745" height="317" alt="image" src="https://github.com/user-attachments/assets/8187634f-4ccf-48f2-8f52-3dda892b6cdb" />

## Как устроено

Фронтенд ходит в бэкенд по адресам:
- `GET /api/notes` — получить список заметок из базы
- `POST /api/notes` — сохранить новую заметку в базу

Бэкенд подключается к PostgreSQL по сети (хост/порт из переменных окружения) и делает обычные SQL-запросы через `psycopg2`.

## Как запустить

Прежде всего заходим в папку проекта!!

### 1. Поднять базу данных

Нужен установленный Docker.

```bash
docker compose up -d
```

Это поднимет PostgreSQL на `localhost:5432` 
<img width="2342" height="345" alt="image" src="https://github.com/user-attachments/assets/9313029d-c3cf-43fe-9f28-18e41d45b4be" />

### 2. Установить зависимости бэкенда

```bash
cd backend
python3 -m venv venv
source venv/bin/activate      на Windows: venv\Scripts\activate (крик единственного виндоус юзера в нашей звездной компании)
pip install -r requirements.txt
```

### 3. Запустить бэкенд

```bash
python app.py (PORT=5001 python app.py для нас мак юзеров а то 5000 занят оказывается)
```

Приложение поднимется на **http://localhost:5000** и отдаёт фронтенд.

# Итог

Мы собрали сервис пикми Заметки с разделением на frontend, backend и базу данных.

- Frontend — HTML/JS, общается с backend по HTTP.
- Backend — Flask, предоставляет GET /api/notes и POST /api/notes, работает с базой через psycopg2.
- База — отдельный PostgreSQL 16 в Docker-контейнере, данные хранятся в volume db_data.
- Проверка — добавленная заметка остаётся после перезагрузки страницы.
